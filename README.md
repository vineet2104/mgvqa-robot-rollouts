### Real robot experiment rollouts for MG-VQA

This repository contains video rollouts from real robot experiments for the MG-VQA project. There are four folders shared: COUNT, FIND, COMPARE and BENEATH corresponding to the four task categories in MG-VQA.
Inside each folder you can find successful and failure cases using two VLMs in manipulation mode: GPT 6 Astra and Qwen 3.8 Flash Next.
